Entry for [The Funniest Out-of-Office](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf) on make.fun: one line of out-of-office auto-reply, the funniest we can make it, in 140 characters or fewer. A judge model picks the line that lands hardest.

## Run it

```sh
node main.ts
```

The program writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), UTF-8, 1–140 characters, no trailing newline.
